# service-container

Provides a Symfony dependency injection container for WordPress, configured like a Symfony kernel.

## Compatibility

| Symfony | PHP 8.1 | PHP 8.2 | PHP 8.3 | PHP 8.4 | PHP 8.5 |
|---------|:-------:|:-------:|:-------:|:-------:|:-------:|
| 6.4     |   ✅    |   ✅    |   ✅    |   ✅    |   ✅    |
| 7.4     |    –    |   ✅    |   ✅    |   ✅    |   ✅    |
| 8.0     |    –    |    –    |    –    |   ✅    |   ✅    |
| 8.1     |    –    |    –    |    –    |   ✅    |   ✅    |
| 8.2+    |    –    |    –    |    –    |   ❓    |   ❓    |

✅ tested in CI · ❓ allowed by `composer.json`, not tested yet · – not supported by that Symfony version
